# Smart T&C Summary (Flask)
1. Install Python 3.9+.  2. `pip install -r requirements.txt`
3. For reading pictures on the server, install Tesseract OCR (Windows: https://github.com/UB-Mannheim/tesseract/wiki). If it is missing, the site automatically reads pictures in the browser instead (needs internet).
4. `python app.py` then open http://127.0.0.1:5000
